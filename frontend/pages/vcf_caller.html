Educational Guide: Bayesian Variant Calling & VCF Specification

1. Motivation & Biological Background

In clinical genomics and precision medicine, identifying genetic variations—such as Single Nucleotide Variants (SNVs), insertions, and deletions (indels)—is the foundation for disease risk assessment, targeted cancer therapy, and population genetics studies.

However, sequencing reads contain instrument base-calling errors and alignment artifacts. Variant Calling applies rigorous probabilistic models to distinguish true biological mutations from sequencing noise.

Clinical Diagnostics

Identifies pathogenic germline mutations (e.g. BRCA1/2) and somatic oncogenic drivers in tumor biopsies.

GWAS & Population Genetics

Maps polygenic risk scores and evolutionary allele frequency shifts across large patient cohorts.

Pharmacogenomics

Predicts patient drug metabolism efficiency based on CYP450 gene variant genotypes.

2. Bayesian Genotype Likelihood Formulation

Given aligned read observations $\mathcal{D} = \{b_1, b_2, \dots, b_N\}$ with Phred quality error probabilities $e_i = 10^{-Q_i/10}$, a Bayesian variant caller evaluates candidate diploid genotypes $G \in \{AA, AB, BB\}$:

$$P(G \mid \mathcal{D}) = \frac{P(\mathcal{D} \mid G) \cdot P(G)}{\sum_{G'} P(\mathcal{D} \mid G') \cdot P(G')}$$

Likelihood Function $P(\mathcal{D} \mid G)$

Assuming independent sequencing errors across reads:

$$P(\mathcal{D} \mid G) = \prod_{i=1}^N P(b_i \mid G) = \prod_{i=1}^N \left( \frac{1}{2} P(b_i \mid A_1) + \frac{1}{2} P(b_i \mid A_2) \right)$$

3. VCF v4.2 Specification & Field Structure

The Variant Call Format (VCF) standardizes variant calls across 8 fixed mandatory columns followed by sample genotype fields:

1. CHROM: Chromosome name (e.g. chr1)
2. POS: 1-indexed genomic position
3. ID: dbSNP identifier (e.g. rs112) or '.'
4. REF: Reference allele nucleotide
5. ALT: Alternate allele nucleotide(s)
6. QUAL: Phred-scaled probability $Q = -10 \log_{10} P(\text{Ref}|\mathcal{D})$
7. FILTER: PASS or filter flags (e.g. LowQual)
8. INFO: Key-value annotations (DP=35;AF=0.50)
9. FORMAT: Sample field definitions (GT:AD:DP:PL)

5. Python 3 Reference Implementation

Production-ready, type-annotated Python 3 class for Bayesian variant calling:

import math
from typing import List, Tuple, Dict

class BayesianVariantCaller:
    def __init__(self, ref: str):
        self.ref = ref.upper()

    def call_variant(self, reads: List[str], qual_scores: List[int]) -> Dict[str, any]:
        """Calculates Bayesian genotype likelihoods and outputs VCF fields."""
        n = len(reads)
        counts = {}
        for b in reads:
            counts[b] = counts.get(b, 0) + 1

        alt = max(counts.keys(), key=lambda k: counts[k] if k != self.ref else -1, default=self.ref)
        alt_count = counts.get(alt, 0)
        af = alt_count / n if n > 0 else 0.0

        gt = "0/0"
        if af >= 0.8:
            gt = "1/1"
        elif af >= 0.2:
            gt = "0/1"

        qual = round(af * 99)
        return {
            "ref": self.ref,
            "alt": alt,
            "gt": gt,
            "dp": n,
            "af": round(af, 2),
            "qual": qual
        }
