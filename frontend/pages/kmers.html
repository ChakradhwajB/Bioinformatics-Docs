Educational Guide: K-mer Frequency Analysis

1. Motivation & Biological Background

A $k$-mer is a continuous substring of length $k$ contained within a biological sequence. Extracting overlapping $k$-mers using a sliding window of step size 1 forms the foundational pillar for alignment-free sequence analysis, de novo genome assembly via De Bruijn graphs, and metagenomic species identification.

De Bruijn Genome Assembly

Constructs assembly graphs where nodes represent $(k-1)$-mers and directed edges represent $k$-mer overlaps.

Metagenomic Species Profiling

Matches read $k$-mer signatures against taxonomic databases (e.g. Kraken2) for instant species identification.

Replication Origin ($oriC$) Mining

Identifies hyper-frequent $DnaA$ box motifs where bacterial DNA replication initiation occurs.

Historical Origin: Pioneered for genome assembly by Pavel A. Pevzner, Haixu Tang, and Michael S. Waterman in 2001, replacing traditional overlap-layout-consensus methods with $k$-mer Eulerian paths.

2. Mathematical Formulation & Sliding Window Theory

Given a sequence $S = s_1 s_2 \dots s_N$ of length $N$ over alphabet $\Sigma$ ($|\Sigma| = 4$ for DNA), the multiset of extracted overlapping $k$-mers $\mathcal{K}_k(S)$ is defined as:

$$\mathcal{K}_k(S) = \{ S[i \dots i+k-1] \mid 1 \le i \le N - k + 1 \}$$

Fundamental Combinatorial Formulas

  • Total extracted $k$-mers: $C(N, k) = \max(0, N - k + 1)$
  • Maximum possible distinct $k$-mers for alphabet size $|\Sigma|$: $|\Sigma|^k = 4^k$

Frequency Distribution Function

The frequency $f(w)$ of a specific $k$-mer word $w \in \Sigma^k$ is given by:

$$f(w) = \sum_{i=1}^{N-k+1} \mathbb{I}\Big(S[i \dots i+k-1] = w\Big)$$

Formal Time & Space Complexity Analysis

Time Complexity: $\mathcal{O}(N \cdot k)$ Sliding a window across $N - k + 1$ positions. String slicing takes $\mathcal{O}(k)$ time per position. (Note: 2-bit rolling hash reduces this to $\mathcal{O}(N)$).
Space Complexity: $\mathcal{O}(\min(N-k+1, 4^k) \cdot k)$ Stores up to $\min(N-k+1, 4^k)$ unique $k$-mer keys in a hash table dictionary.

4. Python 3 Reference Implementation

Production-ready Python module with canonical $k$-mer profiling and frequency spectrum analysis:

from collections import Counter
from typing import Dict, List, Tuple

def get_canonical_kmer(kmer: str) -> str:
    """Returns lexicographically smallest representation between k-mer and its reverse complement."""
    comp_map = str.maketrans('ATCGatcg', 'TAGCtagc')
    rev_comp = kmer.translate(comp_map)[::-1]
    return min(kmer, rev_comp)

def profile_kmers(
    sequence: str, 
    k: int, 
    canonical: bool = False
) -> Dict[str, int]:
    """
    Extracts overlapping k-mers from sequence and calculates frequency distribution.

    Args:
        sequence (str): Target DNA, RNA, or protein sequence string.
        k (int): Length of sliding window k-mer substring.
        canonical (bool): If True, collapses double-stranded k-mers with reverse complements.

    Returns:
        Dict[str, int]: Mapping of k-mer strings to integer frequency counts.
    """
    seq_clean = sequence.upper().strip()
    n = len(seq_clean)

    if k <= 0 or k > n:
        return {}

    kmer_counts: Counter = Counter()

    for i in range(n - k + 1):
        kmer = seq_clean[i:i+k]
        if canonical:
            kmer = get_canonical_kmer(kmer)
        kmer_counts[kmer] += 1

    return dict(kmer_counts)

def find_most_frequent_kmers(sequence: str, k: int) -> Tuple[List[str], int]:
    """Identifies the most frequent k-mer(s) and their maximum count."""
    counts = profile_kmers(sequence, k)
    if not counts:
        return [], 0

    max_freq = max(counts.values())
    most_frequent = [kmer for kmer, freq in counts.items() if freq == max_freq]

    return most_frequent, max_freq
