Educational Guide: High-Throughput Quality Control & Phred Scoring

1. Motivation & Biological Background

Next-Generation Sequencing (NGS) platforms such as Illumina sequencing-by-synthesis and Oxford Nanopore direct RNA/DNA sequencing generate billions of short biological sequence reads per instrument run. However, raw physical signals—fluorescent intensity pulses or ionic current disruptions—are prone to optical noise, phasing de-synchronization, and chemistry degradation over cycle length.

To distinguish true genetic variants (SNPs and indels) from instrument error artifacts, every sequence base is accompanied by a quantitative probability score indicating base-calling confidence.

Variant Calling Accuracy

Filtering out low-quality bases ($Q < 20$) prevents false-positive single nucleotide polymorphism (SNP) calls in medical diagnostics.

De Novo Assembly

Erroneous low-frequency k-mers generated by dirty reads clutter De Bruijn graphs with dead-end tips and false bubble paths.

Alignment MAPQ

Read mappers use per-base quality scores to calculate global mapping quality ($MAPQ$) against reference genomes.

2. The 4-Line FASTQ Format Standard

A FASTQ file consists of repeating 4-line text blocks representing single sequencing reads:

Line 1: @SIM_HISEQ2000:1:1101:10000:20000 1:N:0:GATCAG
Line 2: GATCGGAAGAGCACACGTCTGAACTCCAGTCAC
Line 3: +
Line 4: IIIIIIIIIIIIIIIIIIIIIIIIIIIHFFCCC

Quality characters in Line 4 use Sanger Phred+33 ASCII encoding, mapping integer quality scores $Q \in [0, 42]$ into printable ASCII characters.

3. Mathematical Derivation of Phred Quality Scores ($Q$)

The Phred quality score $Q$ is defined logarithmically relative to base-call error probability $P_e = P(\text{Base Call is Wrong})$:

$$Q = -10 \log_{10} P_e \quad \Longleftrightarrow \quad P_e = 10^{-Q / 10}$$
Q10 Score
90.0% Accuracy
$P_e = 0.1000$ (1 in 10)
Q20 Score
99.0% Accuracy
$P_e = 0.0100$ (1 in 100)
Q30 Score
99.9% Accuracy
$P_e = 0.0010$ (1 in 1,000)
Q40 Score
99.99% Accuracy
$P_e = 0.0001$ (1 in 10,000)

Expected Errors in a Read

To calculate expected error count $E$ across a read of length $L$:

$$E = \sum_{i=1}^L P_{e, i} = \sum_{i=1}^L 10^{-Q_i / 10}$$

4. ASCII Encoding Standards (Phred+33 vs Phred+64)

To store integer quality scores ($Q \in [0, 93]$) compactly without introducing whitespace separators between numbers, every integer score is mapped to a single ASCII character using an offset:

Sanger / Illumina 1.8+ (Phred+33):

Offset = +33. Uses printable ASCII characters from '!' (ASCII 33, $Q=0$) up to '~' (ASCII 126, $Q=93$).

$$Q = \text{ord}(\text{char}) - 33$$
Legacy Illumina 1.3 / 1.5 (Phred+64):

Offset = +64. Uses printable ASCII characters from '@' (ASCII 64, $Q=0$) up to 'h' (ASCII 104, $Q=40$).

$$Q = \text{ord}(\text{char}) - 64$$

5. FastQC Quality Assurance Metrics

FastQC evaluates raw sequencing reads across key diagnostic modules prior to alignment:

1. Per Base Sequence Quality Shows boxplots of Phred quality scores across all read positions (1 to $L$). Quality typically drops near the 3' end due to fluorophore degradation and phasing.
2. Per Sequence GC Content Plots the distribution of GC content per read against a theoretical normal distribution. Bimodal distributions indicate contamination or severe PCR enrichment bias.
3. Adapter Contamination & Trimming Detects residual Illumina TruSeq or Nextera synthetic adapter sequences resulting from short DNA fragment read-through, requiring adapter removal via tools like Cutadapt or Trimmomatic.

7. Python 3 Reference Implementation

Production-ready, type-annotated Python 3 code for FASTQ parsing, quality scoring, and read trimming:

from typing import Dict, List, Any, Iterable

def phred_to_probability(q: int) -> float:
    """Calculates base error probability from Phred quality score P = 10^(-Q/10)"""
    return 10.0 ** (-q / 10.0)

def parse_fastq(lines: Iterable[str]) -> Dict[str, Any]:
    """Parses an iterable of 4-line FASTQ records into structured read dictionaries."""
    clean_lines = [line.strip() for line in lines if line.strip()]
    records = []
    i = 0
    while i + 3 < len(clean_lines):
        header, seq, strand, qual = clean_lines[i:i+4]
        if header.startswith("@") and strand.startswith("+"):
            scores = [ord(char) - 33 for char in qual]
            avg_q = sum(scores) / len(scores) if scores else 0.0
            records.append({
                "header": header[1:],
                "sequence": seq,
                "phred_scores": scores,
                "avg_quality": round(avg_q, 2)
            })
            i += 4
        else:
            i += 1
    return {"read_count": len(records), "records": records}

def trim_low_quality(sequence: str, phred_scores: List[int], min_q: int = 20) -> str:
    """Trims read sequence from 3' end until base quality >= min_q"""
    idx = len(phred_scores)
    while idx > 0 and phred_scores[idx - 1] < min_q:
        idx -= 1
    return sequence[:idx]
