Educational Guide: Probabilistic Sequence Decoding & HMM Formalism

1. Motivation & Biological Background

In computational genomics, observed sequences of nucleotides ($A, C, G, T$) or amino acids are generated by underlying functional genomic states that cannot be observed directly. For example, a chromosome consists of alternating genomic domains such as gene promoters, exons, introns, intergenic spacers, and epigenetic chromatin marks.

CpG Island Promoter Finding

Identifies hypomethylated gene promoter regions enriched in CG dinucleotides ($\text{CpG+}$ vs $\text{CpG-}$ states).

Eukaryotic Gene Structure

Parses complex gene structures into Exon, Intron, 5' UTR, 3' UTR, and Splice Site states (e.g., GENSCAN).

Transmembrane Topology

2. Hidden Markov Model Formalism & Probability Space

A Hidden Markov Model (HMM) is defined mathematically as a 5-tuple $\lambda = (Q, \Sigma, A, B, \pi_0)$:

  • Alphabet $\Sigma$: The finite set of observable symbols, e.g. $\Sigma = \{A, C, G, T\}$.
  • Hidden State Space $Q$: The set of unobserved internal states, e.g. $Q = \{\text{CpG+}, \text{CpG-}\}$.
  • Transition Matrix $A = (a_{kl})$: $a_{kl} = P(\pi_i = l \mid \pi_{i-1} = k)$, the probability of transitioning from state $k$ to state $l$.
  • Emission Matrix $B = (e_k(b))$: $e_k(b) = P(x_i = b \mid \pi_i = k)$, the probability that state $k$ emits symbol $b$.
  • Initial Distribution $\pi_0$: Prior probability vector $\pi_0(k) = P(\pi_1 = k)$.

Joint Probability Distribution

The joint probability of observing sequence $x = (x_1, \dots, x_L)$ along a hidden state path $\pi = (\pi_1, \dots, \pi_L)$ is:

$$P(x, \pi) = \pi_0(\pi_1) e_{\pi_1}(x_1) \prod_{i=2}^L a_{\pi_{i-1}\pi_i} e_{\pi_i}(x_i)$$

3. The Three Fundamental Problems of HMMs

1. Evaluation (Forward-Backward) Computes total likelihood $P(x) = \sum_\pi P(x, \pi)$ of sequence $x$ over all possible hidden paths using the Forward Algorithm.
2. Decoding (Viterbi Algorithm) Finds the single optimal hidden state sequence $\pi^* = \arg\max_\pi P(x, \pi)$ that best explains observed sequence $x$.
3. Learning (Baum-Welch / EM) Estimates optimal transition $A$ and emission $B$ parameters from unannotated sequence data using Expectation-Maximization.

4. Derivation of Viterbi Recurrence & Log-Space Math

Let $V(k, i)$ denote the probability of the most likely hidden path ending in state $k$ at observation position $i$:

$$V(k, i) = e_k(x_i) \cdot \max_{l \in Q} \left( V(l, i-1) \cdot a_{lk} \right)$$

Log-Space Underflow Prevention

Multiplying thousands of small probabilities ($P < 1.0$) causes floating-point underflow to zero. Transforming calculations into log-space replaces multiplication with addition:

$$v(k, i) = \log e_k(x_i) + \max_{l \in Q} \left( v(l, i-1) + \log a_{lk} \right)$$

6. Python 3 Reference Implementation

Production-ready, type-annotated Python 3 class implementing log-space Viterbi decoding:

import math
from typing import List, Dict, Tuple

class ViterbiDecoder:
    def __init__(self, states: List[str], start_p: Dict[str, float], trans_p: Dict[str, Dict[str, float]], emit_p: Dict[str, Dict[str, float]]):
        self.states = states
        self.start_p = {s: math.log(start_p[s]) for s in states}
        self.trans_p = {u: {v: math.log(trans_p[u][v]) for v in states} for u in states}
        self.emit_p = {s: {b: math.log(emit_p[s][b]) for b in emit_p[s]} for s in states}

    def decode(self, obs: str) -> Tuple[List[str], float]:
        """Performs log-space Viterbi decoding for observation string obs."""
        n = len(obs)
        V = [{s: self.start_p[s] + self.emit_p[s][obs[0]] for s in self.states}]
        back = []

        for t in range(1, n):
            v_t = {}
            b_t = {}
            char = obs[t]
            for curr in self.states:
                (max_val, best_prev) = max(
                    (V[t - 1][prev] + self.trans_p[prev][curr] + self.emit_p[curr][char], prev)
                    for prev in self.states
                )
                v_t[curr] = max_val
                b_t[curr] = best_prev
            V.append(v_t)
            back.append(b_t)

        (opt_score, best_last) = max((V[-1][s], s) for s in self.states)
        best_path = [best_last]
        for t in range(n - 2, -1, -1):
            best_last = back[t][best_last]
            best_path.append(best_last)

        best_path.reverse()
        return best_path, opt_score
