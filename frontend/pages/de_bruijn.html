Educational Guide: De Bruijn Graph Genome Assembly

1. Motivation & Biological Background

When sequencing an uncharacterized organism whose genome has never been assembled before (such as a newly discovered virus, novel bacterial pathogen, or unstudied plant species), reference-guided read mapping is impossible. Researchers must reconstruct the complete target genome de novo directly from raw sequencing read fragments.

Novel Pathogen Discovery

Reconstructs full viral and bacterial genomes during pandemic outbreaks without relying on existing databases.

Metagenomic Binning

Assembles unculturable microbial genomes from environmental soil, ocean, and human gut microbiome samples.

Cancer Structural Variants

Resolves complex somatic rearrangements, gene fusions, and large insertions in tumor genomes.

2. Overlap-Layout-Consensus (OLC) vs. De Bruijn Graphs

Historically, long Sanger reads were assembled using Overlap-Layout-Consensus (OLC) graphs:

  • OLC Nodes: Individual raw sequencing reads.
  • OLC Edges: Pairwise prefix-suffix alignments between overlapping reads.

The OLC Dilemma: Finding the assembled genome requires finding a Hamiltonian Path (visiting every node exactly once), which is an NP-complete problem ($\mathcal{O}(2^N)$ complexity)!

Pevzner's Eulerian Paradigm Shift

In 2001, Pevzner, Tang, and Waterman introduced a breakthrough transformation: decompose reads into overlapping $k$-mers to construct a De Bruijn Graph:

Nodes (V): Distinct $(k-1)$-mer sequence prefixes and suffixes.
Edges (E): Directed $k$-mer reads connecting prefix $(k-1)$-mer to suffix $(k-1)$-mer.

The Eulerian Advantage: Finding the assembled genome corresponds to finding an Eulerian Path (visiting every edge exactly once), which is solvable in linear time $\mathcal{O}(|E|)$ using Hierholzer's Algorithm!

3. Mathematical Graph Formulation & Degree Conditions

Let $G = (V, E)$ denote the directed De Bruijn graph constructed from $k$-mer set $K$. A directed graph contains a valid Eulerian path if and only if it satisfies the degree balance conditions:

$$\text{Start Node } u: \quad \text{out-degree}(u) - \text{in-degree}(u) = 1$$

$$\text{End Node } v: \quad \text{in-degree}(v) - \text{out-degree}(v) = 1$$

$$\text{All Intermediate Nodes } w: \quad \text{in-degree}(w) = \text{out-degree}(w)$$

4. Graph Cleanup & Error Artifact Removal

Raw NGS reads contain base-calling sequencing errors that corrupt De Bruijn graphs:

1. Dead-End Tip Trimming Errors near read ends create low-coverage dead-end branches (tips) that are pruned by removing low-frequency $k$-mers.
2. Bubble Popping Heterozygous SNPs or internal read errors split paths into parallel bubbles that rejoin downstream. Assemblers merge bubbles based on coverage.

6. Python 3 Reference Implementation

Production-ready Python 3 implementation of De Bruijn Graph construction and Hierholzer's Eulerian path algorithm:

from collections import defaultdict, deque
from typing import List, Dict, Tuple

def build_de_bruijn(reads: List[str], k: int) -> Dict[str, List[str]]:
    """Constructs De Bruijn graph adjacency list from k-mers."""
    graph = defaultdict(list)
    for read in reads:
        for i in range(len(read) - k + 1):
            kmer = read[i:i+k]
            prefix, suffix = kmer[:-1], kmer[1:]
            graph[prefix].append(suffix)
    return graph

def find_eulerian_path(graph: Dict[str, List[str]]) -> List[str]:
    """Hierholzer's linear O(|E|) algorithm for finding Eulerian Path."""
    in_deg = defaultdict(int)
    out_deg = defaultdict(int)
    nodes = set(graph.keys())
    for u, neighbors in graph.items():
        out_deg[u] += len(neighbors)
        for v in neighbors:
            in_deg[v] += 1
            nodes.add(v)

    start_node = next(iter(nodes))
    for node in nodes:
        if out_deg[node] - in_deg[node] == 1:
            start_node = node
            break

    adj = {u: deque(neighbors) for u, neighbors in graph.items()}
    stack = [start_node]
    path = []

    while stack:
        u = stack[-1]
        if u in adj and adj[u]:
            v = adj[u].popleft()
            stack.append(v)
        else:
            path.append(stack.pop())

    path.reverse()
    return path

def assemble_genome(path: List[str]) -> str:
    """Reconstructs genome sequence from Eulerian node path."""
    if not path: return ""
    return path[0] + "".join(node[-1] for node in path[1:])
