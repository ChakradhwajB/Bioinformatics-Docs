Educational Guide: Deep Learning Architectures & Genomic Transformers

1. Motivation & Biological Background

Over 98% of the human genome consists of non-coding DNA. Rather than coding for proteins directly, non-coding regions harbor complex regulatory syntax—promoters, enhancers, silencers, and insulator elements—that dictate when, where, and how much genes are expressed.

Non-Coding Variant Effect

Predicts how non-coding SNPs alter transcription factor binding, chromatin accessibility, and gene expression levels.

Promoter & Enhancer Syntax

Decodes motif spacing, orientation, and combinatorial grammar governing cell-type specific gene regulation.

Genomic Foundation Models

Pre-trains self-supervised Transformer models (DNABERT, Enformer, HyenaDNA) across multi-species whole genomes.

2. Sequence One-Hot Encoding & 1D CNN Motif Detectors

Raw DNA sequences of length $L$ are converted into binary one-hot matrices $\mathbf{X} \in \mathbb{R}^{L \times 4}$, where $A=[1,0,0,0]^T, C=[0,1,0,0]^T, G=[0,0,1,0]^T, T=[0,0,0,1]^T$.

1D Convolutional Neural Network (CNN) filters $W \in \mathbb{R}^{k \times 4}$ act as learnable Position Weight Matrices (PWMs) scanning along the sequence:

$$Y_i = \text{ReLU} \left( \sum_{j=1}^k \sum_{c=1}^4 W_{j, c} \cdot X_{i+j-1, c} + b \right)$$

3. Transformer Self-Attention Architectures for Genomes

Long-range enhancer-promoter loops interact over distances up to $100\text{ kb}$. Multi-head self-attention calculates pairwise contextual dependencies across all sequence positions simultaneously:

$$\text{Attention}(Q, K, V) = \text{softmax} \left( \frac{Q K^T}{\sqrt{d_k}} \right) V$$

4. Zero-Shot Variant Effect Prediction

To evaluate a non-coding mutation, the model executes forward passes on both reference ($x_{ref}$) and mutated ($x_{alt}$) sequence windows. The variant effect score is calculated as $\Delta = f(x_{alt}) - f(x_{ref})$.

6. PyTorch Reference Implementation

Production-ready, type-annotated PyTorch module combining 1D CNN motif extraction with Transformer self-attention:

import torch
import torch.nn as nn

class GenomicTransformerCNN(nn.Module):
    def __init__(self, d_model: int = 128, nhead: int = 4, num_layers: int = 2):
        super().__init__()
        # 1D CNN motif scanner
        self.conv1d = nn.Conv1d(in_channels=4, out_channels=d_model, kernel_size=6, padding=3)
        self.relu = nn.ReLU()
        
        # Transformer self-attention encoder
        encoder_layer = nn.TransformerEncoderLayer(d_model=d_model, nhead=nhead, batch_first=True)
        self.transformer = nn.TransformerEncoder(encoder_layer, num_layers=num_layers)
        self.classifier = nn.Linear(d_model, 1)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """x shape: [batch, 4, seq_len]"""
        feat = self.relu(self.conv1d(x)).transpose(1, 2)  # [batch, seq_len, d_model]
        attn_out = self.transformer(feat)
        pooled = attn_out.mean(dim=1)
        return torch.sigmoid(self.classifier(pooled))
