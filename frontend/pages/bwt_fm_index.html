Educational Guide: Compressed Indexing & FM-Index Short-Read Mapping

1. Motivation & Biological Background

Next-Generation Sequencing (NGS) platforms such as Illumina NovaSeq and Oxford Nanopore generate hundreds of millions of short genomic DNA reads (100–150 bp) per instrument run. To discover disease-causing single-nucleotide variants, measure transcriptomic expression, or detect structural mutations, every individual read must be accurately mapped to its exact genomic locus within a 3-billion-base reference genome.

Classical dynamic programming sequence alignment algorithms (such as Needleman-Wunsch or Smith-Waterman) run in quadratic time $\mathcal{O}(N \cdot M)$. Attempting to align $10^8$ short reads of length $M=150$ against a human reference genome of length $N = 3 \times 10^9$ would require over $4.5 \times 10^{19}$ operations—consuming decades of high-performance computing cluster execution time!

The Memory Bottleneck of Hash-Based Seed Indexes

Early alignment tools (such as BLAST, BLAT, and MAQ) indexed reference genomes using $k$-mer hash tables. However, storing every 15-mer position in a 3-gigabase genome requires over 12–32 GB of RAM. When scaling to multi-gigabase plant genomes or metagenomic databases, hash table memory footprints become completely intractable.

2. Burrows-Wheeler Transform & Last-First (LF) Mapping

Invented by Michael Burrows and David Wheeler in 1994 for data compression, the Burrows-Wheeler Transform (BWT) reorganizes a text string into runs of identical characters, making it exceptionally compressible while preserving full reversibility.

Given a text $T$ appended with a unique terminal character "$" (which is defined as lexicographically smaller than any nucleotide), the BWT is constructed by:

  1. Forming all $N$ cyclic rotations of $T\$$.
  2. Sorting these rotations lexicographically to create the $N \times N$ matrix $M_{BWT}$.
  3. Extracting the last column of $M_{BWT}$, designated as $L = BWT(T)$.

The Last-First (LF) Mapping Property

The fundamental mathematical engine of the FM-Index is the Last-First (LF) Mapping Property:

The $i$-th occurrence of character $c$ in column $L$ (the Last column) corresponds to the exact same physical occurrence of character $c$ in column $F$ (the First column).

To calculate the row index in column $F$ corresponding to position $i$ in column $L$, we evaluate the LF-mapping equation:

$$LF(i) = C[L[i]] + \text{Occ}(L[i], i)$$
  • $C[c]$: The total count of characters in text $T$ that are lexicographically strictly smaller than $c$.
  • $\text{Occ}(c, i)$: The number of occurrences of character $c$ in column $L[0 \dots i-1]$ (up to row $i$).

3. Mathematical Derivation of FM-Index Backward Search

Traditional string matching searches left-to-right. In contrast, the FM-Index performs Backward Search, matching pattern $P = P[0 \dots m-1]$ from right to left ($P[m-1], P[m-2], \dots, P[0]$).

Backward search tracks a row range $[\text{top}, \text{bot}]$ in the sorted $M_{BWT}$ matrix that prefix-matches the pattern query:

$$\text{Initial Range: } \text{top}_0 = 0, \quad \text{bot}_0 = N - 1$$

$$\text{For step } k = m-1 \text{ down to } 0 \text{ with character } c = P[k]:$$

$$\text{top}_{new} = C[c] + \text{Occ}(c, \text{top})$$

$$\text{bot}_{new} = C[c] + \text{Occ}(c, \text{bot} + 1) - 1$$

If $\text{top}_{new} \le \text{bot}_{new}$, all rows in index range $[\text{top}, \text{bot}]$ match suffix $P[k \dots m-1]$. If $\text{top} > \text{bot}$, the pattern does not exist in reference genome $T$.

4. Time & Space Complexity Analysis

Search Time Complexity: $\mathcal{O}(|P|)$ Backward search matches each character of query pattern $P$ in constant time $\mathcal{O}(1)$ via $C$ and $\text{Occ}$ array lookups, completely independent of reference genome size $N$.
Index Space Complexity: $\mathcal{O}(N)$ By sampling the Occ matrix and Suffix Array at fixed intervals (e.g., every 32 positions), the human genome index occupies less than 2.5 GB of RAM.

5. Step-by-Step Worked Example & LF-Mapping Trace

Consider reference text $T = \text{"BANANA\$"}$ ($N=7$). Sorted matrix $M_{BWT}$ and $BWT(T) = \text{"ANNB\$AA"}$:

Row ($i$) SA[$i$] F (First) Rotated String ($T$) L (BWT)
0 6 $ $BANANA A
1 5 A A$BANAN N
2 3 A ANA$BAN N
3 1 A ANANA$B B
4 0 B BANANA$ $
5 4 N NA$BANA A
6 2 N NANA$BA A

Backward Search Execution for $P = \text{"ANA"}$

  1. Initialize: $\text{top}_0 = 0, \text{bot}_0 = 6$.
  2. Step 1 ($c = P[2] = \text{'A'}$):
    $\text{top}_1 = C[\text{'A'}] + \text{Occ}(\text{'A'}, 0) = 1 + 0 = 1$.
    $\text{bot}_1 = C[\text{'A'}] + \text{Occ}(\text{'A'}, 7) - 1 = 1 + 3 - 1 = 3$.
    Range = $[1, 3]$ (3 matching suffixes starting with "A").
  3. Step 2 ($c = P[1] = \text{'N'}$):
    $\text{top}_2 = C[\text{'N'}] + \text{Occ}(\text{'N'}, 1) = 5 + 0 = 5$.
    $\text{bot}_2 = C[\text{'N'}] + \text{Occ}(\text{'N'}, 4) - 1 = 5 + 2 - 1 = 6$.
    Range = $[5, 6]$ (2 matching suffixes starting with "NA").
  4. Step 3 ($c = P[0] = \text{'A'}$):
    $\text{top}_3 = C[\text{'A'}] + \text{Occ}(\text{'A'}, 5) = 1 + 1 = 2$.
    $\text{bot}_3 = C[\text{'A'}] + \text{Occ}(\text{'A'}, 7) - 1 = 1 + 3 - 1 = 3$.
    Range = $[2, 3]$ (2 matching occurrences of "ANA").

Matched Suffix Array Offsets:
SA[2] = 3 (BAN[ANA]$)
SA[3] = 1 (B[ANA]NA$)

6. Traceback & Suffix Array Position Reconstruction

Once backward search completes and returns range $[\text{top}, \text{bot}]$, the physical 0-indexed positions in reference genome $T$ are retrieved by reading $\text{SA}[i]$ for $i \in [\text{top}, \text{bot}]$.

7. Python 3 Reference Implementation

Production-ready, type-annotated Python 3 class implementing BWT, $C[]$ table, $\text{Occ}$ tally matrix, and sub-linear backward search:

from typing import List, Dict, Tuple

class FMIndex:
    def __init__(self, reference: str):
        if not reference.endswith("$"):
            reference += "$"
        self.ref = reference
        self.sa = self._build_suffix_array(reference)
        self.bwt = "".join(reference[i - 1] for i in self.sa)
        self.C, self.Occ = self._build_tally_tables(self.bwt)

    def _build_suffix_array(self, text: str) -> List[int]:
        """Constructs the Suffix Array of text."""
        return sorted(range(len(text)), key=lambda i: text[i:])

    def _build_tally_tables(self, bwt: str) -> Tuple[Dict[str, int], Dict[str, List[int]]]:
        """Builds C[] smaller-character count and Occ[][] tally matrix."""
        alphabet = sorted(list(set(bwt)))
        C = {}
        total = 0
        for char in alphabet:
            C[char] = total
            total += bwt.count(char)

        Occ = {char: [0] * (len(bwt) + 1) for char in alphabet}
        for i, char in enumerate(bwt):
            for c in alphabet:
                Occ[c][i + 1] = Occ[c][i] + (1 if c == char else 0)

        return C, Occ

    def search(self, pattern: str) -> List[int]:
        """
        Executes sub-linear O(|P|) FM-Index backward search.
        Returns list of 0-indexed genomic positions.
        """
        top, bot = 0, len(self.bwt) - 1
        for char in reversed(pattern):
            if char not in self.C:
                return []
            top = self.C[char] + self.Occ[char][top]
            bot = self.C[char] + self.Occ[char][bot + 1] - 1
            if top > bot:
                return []

        return sorted([self.sa[i] for i in range(top, bot + 1)])
